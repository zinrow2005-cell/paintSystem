# 小小畫家學習樂園 V1.7.36｜全螢幕浮動筆觸與超大字練習版

本版以 V1.7.35 為基礎，針對 iPad／手機的全螢幕畫畫與寫字操作再精簡。

## V1.7.36 重點修正
- 全螢幕畫板仍維持 100% viewport Canvas，控制元件只浮在畫布角落，不參與 Canvas 版面計算。
- 原本下方整條「粗細＋透明度」改成左下角可收合的 `🖌️ 筆觸` 浮動工具；進入全螢幕時預設收合。
- `上一步／下一步／完成收藏` 獨立固定於右下角，不再形成橫跨畫布的底部工具列。
- 全螢幕英文練習依單字長度與實際螢幕寬高自動放大；短單字會使用更大的描寫字級與字母間距。
- 全螢幕中文只顯示一列田字格，依字數平均使用螢幕寬度，不再重複上下兩列。
- 全螢幕注音只顯示一列，每個音節依螢幕寬度自動放大，不再重複上下兩列。
- 全螢幕只保留 `🎨 畫畫` 與 `✍️ 寫字`；發音仍保留在一般學習頁面，不放進全螢幕。

## 主要功能
- 200 張彩色教材＋200 張黑白線稿。
- 7 種畫具：鉛筆、蠟筆、畫筆、水彩筆、色筆、噴筆、橡皮擦。
- 圓形顏色挑選盤與明暗控制。
- 橡皮擦圓形擦拭範圍提示。
- 底圖透明度 0%～100%，預設 15%。
- 多圖層、文字塗寫、英文／中文發音、作品收藏。
- iPad／iPad mini／Apple Pencil 操作穩定性修正。
- PWA 與 Service Worker；教材圖片採使用時逐步快取。

## GitHub 更新方式
如果 GitHub 已經有 V1.7.35 與 400 張教材圖片，只要上傳「V1.7.36 GitHub 更新小包」內的 7 個檔案，直接覆蓋 Repository 根目錄同名檔案：

```text
index.html
styles.css
app.js
sw.js
manifest.webmanifest
README.md
CORE_SHA256.txt
```

教材圖片與 `lineart.js` 不需要重新上傳。

## 完整版 GitHub Pages 上傳
若使用完整備份版，解壓後把第一層內容放到 Repository 根目錄，確認 `index.html` 直接位於根目錄。GitHub Pages 設為 `Deploy from a branch`、正式分支（通常 `main`）、`/(root)`。

## 快取注意
覆蓋 GitHub 後若 iPad／手機仍看到舊介面，請完全關閉該 Safari 分頁或主畫面 PWA 後重新開啟。V1.7.36 已使用新的 Service Worker cache key。
