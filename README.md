# 小小畫家學習樂園 V1.7.52｜注音拆音・合音・詞彙發音版

本版強化全螢幕寫字的ㄅㄆㄇ發音教學：
- 每個字先逐一播放聲母／介音／韻母／聲調，再播放完整注音。
- 聲調符號以「二聲／三聲／四聲／輕聲」語音播放，避免手機 TTS 忽略符號。
- 提供「完整教學」：逐字拆音＋合音 → 全詞逐音節 → 最後完整中文詞彙。
- 200 筆教材已檢查，中文字數與注音音節數 200/200 對應一致。
